## Installation
To install all the required packages. In a terminal run the command
    pip install -r requirements.txt

## Usage
To run the app, in a terminal run the command

python -m uvicorn backend.capstone_project: app --reload

This will start the server that will be needed to connect to the app.

To start the app, open the App-v1 solution in Visual Studio and run it.
